# ZH-Timemachine

> 一个帮助你查看时间洪流中问题看法变化的 Agent。

在 2026 年 6 月 21 日 23 点到 6 月 22 日凌晨 2 点，纬度 50.935173°N，经度 6.953101°E，NiKo 成功于科隆 Major 捧杯，成功圆梦。

从刚出道时被认为拿到 Major“只是时间问题”，到 18 次梦碎 Major，再到 Major 前接连滑铁卢、不被看好，再到如今科隆夺冠，尼粉开始清算。

我们不难看出，一个问题的答案，在一段时间内往往会发生剧烈的变化，这也是我们这个项目所关注的核心。

## 我们想做什么

输入一个问题，选定一段时间，让 Agent 通过知乎官方 API 搜索，借助 LLM 整理各个时期的观点，并通过时间线观察它们如何变化。

- **搜索**：按时间范围寻找相关内容。
- **概括**：整理各阶段的主要观点，附上原文来源。
- **回看**：用图表呈现变化，点击即可查看对应证据。

这里的“主要观点”来自检索到的样本，不代表知乎全站。

## 开发

Electron · React · TypeScript · AI SDK · Recharts · SQLite

使用 Node.js 24 LTS，在项目目录执行：

```sh
npm ci
npm run dev
```

在“模型与连接”中填写凭证，即可新建研究。支持取消、继续分析和导出研究数据。更多说明见 [开发环境](docs/DEVELOPMENT.md)。
